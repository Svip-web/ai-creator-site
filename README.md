# AI Creator landing

Локальна React/TypeScript-версія мобільного лендингу з фіксованою шириною 393 px.

## Запуск

```bash
npm install
npm run dev
```

Локальна адреса: `http://localhost:3000/`.

## Перевірка production-збірки

```bash
npm run build
```

Публікація та зовнішні сервіси у v1 не підключені.
